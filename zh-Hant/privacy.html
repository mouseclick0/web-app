隱私政策

WebToolBay（以下稱「本站」）重視使用者的個人資料，並依照相關法令以下列方式處理。本政策適用於本站的使用。

最後更新：2026 年 8 月 2 日

1. 處理的資訊

本站原則上不需要註冊帳號。但為提供服務，可能會處理下列資訊。

  • 聯絡表單：姓名、電子信箱、訊息內容（由使用者自行填寫）
  • 天氣功能：在您允許瀏覽器位置權限時的大致座標（由裝置用於發出 API 請求）
  • IP 查詢功能：為取得對外 IP 及相關網路資訊，向外部 IP 查詢服務發出請求
  • 自動保存：瀏覽器語言、主題設定等為使用便利而保存的本機值（localStorage）
  • 伺服器紀錄（主機代管）：GitHub Pages 等代管環境可能會留下一般的存取紀錄

2. 使用目的

  • 提供天氣、日曆、IP 等您所要求的功能
  • 受理並回覆洽詢
  • 排查服務錯誤與改善品質
  • 履行法令規定的義務

3. 保存與銷毀

洽詢內容僅在回覆所需的期間內保存，目的達成後會立即銷毀。保存在瀏覽器 localStorage 中的設定值，在您自行刪除或清除瀏覽器資料後即被移除。位置資訊不會長期保存在伺服器上，僅用於處理查詢請求。

4. 第三方服務

為提供功能，本站可能使用下列外部服務。

  • Open-Meteo（天氣資料）
  • ipify / ipwho.is 等 IP 與地區資訊 API
  • Formspree（聯絡表單傳送）
  • Google Fonts 等字型與 CDN
  • GitHub Pages（主機代管）

各服務可能依照其所屬公司的政策處理資料。

5. Cookie 與個人化廣告（AdSense）

今後如使用 Google AdSense 等廣告服務，包括 Google 在內的第三方供應商可能會使用 Cookie，依據使用者的造訪資訊放送廣告。您可以在 Google 廣告設定停用個人化廣告，也可以在 www.aboutads.info 停用第三方供應商的個人化廣告。

若設定為不使用 Cookie，可能不會顯示個人化廣告。

6. 使用者的權利

使用者可以透過聯絡頁面，要求查閱、更正或刪除與本人相關的洽詢內容。保存在瀏覽器中的設定，可在自己的裝置上直接管理。

7. 兒童的個人資料

本站未經營以兒童為對象的服務，也不會刻意蒐集未滿 14 歲兒童的個人資料。

8. 政策變更

本政策如有變更，將修改頁面上方的更新日期並在本站公告。

9. 聯絡方式

與個人資料相關的洽詢，請透過聯絡頁面提出。
