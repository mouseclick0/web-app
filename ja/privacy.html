プライバシーポリシー

WebToolBay（以下「本サイト」）は利用者の個人情報を重要なものと考え、関連法令に従って以下のとおり取り扱います。本ポリシーは本サイトのご利用に適用されます。

最終更新日: 2026年8月2日

1. 取り扱う情報

本サイトは原則として会員登録を必要としません。ただし、サービス提供のために以下の情報を取り扱う場合があります。

  • お問い合わせフォーム: お名前、メールアドレス、メッセージの内容（利用者が直接入力）
  • 天気機能: ブラウザの位置情報を許可した場合のおおよその座標（端末からのAPIリクエストに使用）
  • IP確認機能: グローバルIPおよび関連するネットワーク情報を取得するための外部IP照会サービスへのリクエスト
  • 自動的な保存: ブラウザの言語やテーマ設定など、利便性のためのローカル保存値（localStorage）
  • サーバーログ（ホスティング）: GitHub Pagesなどのホスティング環境で一般的なアクセスログが記録される場合があります

2. 利用目的

  • 天気・カレンダー・IPなど、ご要望の機能の提供
  • お問い合わせの受付と返信
  • 不具合の確認と品質の改善
  • 法令上の義務の履行

3. 保管と削除

お問い合わせの内容は返信に必要な期間のみ保管し、目的を達成した後は遅滞なく削除します。ブラウザのlocalStorageに保存された設定値は、利用者ご自身が削除するか、ブラウザのデータを消去すると取り除かれます。位置情報はサーバーに長期保存せず、照会リクエストの処理にのみ使用します。

4. 第三者サービス

機能の提供のため、以下の外部サービスを利用する場合があります。

  • Open-Meteo（天気データ）
  • ipify / ipwho.is などのIP・地域情報API
  • Formspree（お問い合わせフォームの送信）
  • Google Fontsなどのフォント・CDN
  • GitHub Pages（ホスティング）

各サービスは、それぞれの事業者のポリシーに従ってデータを取り扱う場合があります。

5. Cookieとパーソナライズ広告（AdSense）

今後Google AdSenseなどの広告サービスを利用する場合、Googleを含む第三者配信事業者がCookieを使用し、利用者の訪問情報に基づいて広告を配信することがあります。パーソナライズ広告はGoogle広告設定で無効にでき、第三者配信事業者によるパーソナライズ広告の利用はwww.aboutads.infoで無効にできます。

Cookieを使用しない設定にすると、パーソナライズ広告が表示されない場合があります。

6. 利用者の権利

利用者はお問い合わせページを通じて、ご自身に関するお問い合わせ内容の開示・訂正・削除を求めることができます。ブラウザに保存された設定は、ご自身の端末で直接管理できます。

7. 児童の個人情報

本サイトは児童を対象としたサービスを運営しておらず、満14歳未満の児童の個人情報を故意に収集することはありません。

8. ポリシーの変更

本ポリシーを変更した場合は、ページ上部の更新日を修正し、本サイトに掲載します。

9. お問い合わせ

個人情報に関するお問い合わせはお問い合わせページからお送りください。
