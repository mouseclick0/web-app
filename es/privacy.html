Política de privacidad

WebToolBay (en adelante, «el sitio») considera importante la privacidad de sus usuarios y trata los datos personales del modo que se describe a continuación, conforme a la legislación aplicable. Esta política se aplica al uso del sitio.

Última actualización: 2 de agosto de 2026

1. Información que tratamos

El sitio no exige crear una cuenta. Aun así, para prestar el servicio puede ser necesario tratar la siguiente información.

  • Formulario de contacto: nombre, correo electrónico y contenido del mensaje, introducidos por el propio usuario
  • Función de clima: coordenadas aproximadas, si concedes el permiso de ubicación del navegador, utilizadas por tu dispositivo para hacer la petición a la API
  • Función de consulta de IP: una petición a un servicio externo para obtener tu IP pública y los datos de red asociados
  • Almacenamiento automático: valores locales como el idioma del navegador o el tema elegido, guardados por comodidad (localStorage)
  • Registros del servidor (alojamiento): el entorno de alojamiento, como GitHub Pages, puede registrar los accesos habituales

2. Finalidad del tratamiento

  • Prestar las funciones que solicitas, como el clima, el calendario o la consulta de IP
  • Recibir consultas y responderlas
  • Detectar fallos del servicio y mejorar su calidad
  • Cumplir las obligaciones legales

3. Conservación y supresión

Las consultas se conservan solo durante el tiempo necesario para responderlas y se suprimen sin demora una vez cumplida esa finalidad. Los ajustes guardados en el localStorage del navegador se eliminan cuando los borras tú mismo o cuando limpias los datos del navegador. Los datos de ubicación no se almacenan a largo plazo en ningún servidor: se usan únicamente para procesar la petición.

4. Servicios de terceros

Para ofrecer determinadas funciones pueden utilizarse los siguientes servicios externos.

  • Open-Meteo (datos meteorológicos)
  • ipify / ipwho.is y otras API de IP e información regional
  • Formspree (envío del formulario de contacto)
  • Google Fonts y otros proveedores de fuentes o CDN
  • GitHub Pages (alojamiento)

Cada servicio puede tratar los datos conforme a su propia política.

5. Cookies y publicidad personalizada (AdSense)

Si en el futuro se utilizan servicios publicitarios como Google AdSense, proveedores externos —incluido Google— podrán usar cookies para mostrar anuncios basados en tus visitas. Puedes desactivar la publicidad personalizada en la configuración de anuncios de Google, y puedes rechazar el uso de publicidad personalizada por parte de proveedores externos en www.aboutads.info.

Si desactivas las cookies, es posible que no se muestren anuncios personalizados.

6. Derechos del usuario

Puedes usar la página de contacto para solicitar el acceso, la rectificación o la supresión del contenido de las consultas que te conciernen. Los ajustes guardados en el navegador puedes gestionarlos directamente en tu dispositivo.

7. Privacidad de los menores

El sitio no ofrece un servicio dirigido a menores y no recoge deliberadamente datos personales de menores de 14 años.

8. Cambios en esta política

Cuando esta política cambie, se actualizará la fecha que aparece en la parte superior de la página y se publicará la nueva versión en el sitio.

9. Contacto

Para consultas sobre privacidad, escríbenos desde la página de contacto.
