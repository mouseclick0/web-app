隐私政策

WebToolBay（以下称“本站”）重视用户的个人信息，并依照相关法律法规按以下方式处理。本政策适用于本站的使用。

最后更新：2026 年 8 月 2 日

1. 处理的信息

本站原则上不要求注册账号。但为提供服务，可能会处理以下信息。

  • 联系表单：姓名、电子邮箱、留言内容（由用户自行填写）
  • 天气功能：在您允许浏览器位置权限时的大致坐标（由设备用于发起 API 请求）
  • IP 查询功能：为获取公网 IP 及相关网络信息，向外部 IP 查询服务发起请求
  • 自动保存：浏览器语言、主题设置等为使用便利而保存的本地值（localStorage）
  • 服务器日志（托管）：GitHub Pages 等托管环境可能会记录常规访问日志

2. 使用目的

  • 提供天气、日历、IP 等您所请求的功能
  • 受理并回复咨询
  • 排查服务故障与改进质量
  • 履行法律法规规定的义务

3. 保存与销毁

咨询内容仅在回复所需的期间内保存，目的达成后会立即销毁。保存在浏览器 localStorage 中的设置值，在您自行删除或清除浏览器数据后即被移除。位置信息不会长期保存在服务器上，仅用于处理查询请求。

4. 第三方服务

为提供功能，本站可能使用以下外部服务。

  • Open-Meteo（天气数据）
  • ipify / ipwho.is 等 IP 与地区信息 API
  • Formspree（联系表单发送）
  • Google Fonts 等字体与 CDN
  • GitHub Pages（托管）

各服务可能依照其所属公司的政策处理数据。

5. Cookie 与个性化广告（AdSense）

今后如使用 Google AdSense 等广告服务，包括 Google 在内的第三方供应商可能会使用 Cookie，基于用户的访问信息投放广告。您可以在 Google 广告设置中停用个性化广告，也可以在 www.aboutads.info 停用第三方供应商的个性化广告。

如果设置为不使用 Cookie，可能不会展示个性化广告。

6. 用户的权利

用户可以通过联系页面，要求查阅、更正或删除与本人相关的咨询内容。保存在浏览器中的设置，可在自己的设备上直接管理。

7. 儿童的个人信息

本站不运营面向儿童的服务，也不会有意收集未满 14 周岁儿童的个人信息。

8. 政策变更

本政策如有变更，将修改页面顶部的更新日期并在本站公布。

9. 联系方式

与个人信息相关的咨询，请通过联系页面提交。
