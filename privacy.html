개인정보처리방침

클릭웹도구(이하 “사이트”)는 이용자의 개인정보를 중요하게 생각하며, 관련 법령에 따라 아래와 같이 처리합니다. 본 방침은 사이트 이용에 적용됩니다.

최종 업데이트: 2026년 8월 2일

1. 수집하는 정보

사이트는 기본적으로 회원가입을 요구하지 않습니다. 다만 서비스 제공을 위해 아래 정보가 처리될 수 있습니다.

  • 문의 양식: 이름, 이메일, 메시지 내용(이용자가 직접 입력)
  • 날씨 기능: 브라우저 위치 권한을 허용한 경우 대략적인 위치 좌표(기기에서 API 요청에 사용)
  • IP 찾기 기능: 공인 IP 및 관련 네트워크 정보 조회를 위해 외부 IP 조회 서비스에 요청
  • 자동 수집: 브라우저 언어, 테마 설정 등 이용 편의를 위한 로컬 저장값(localStorage)
  • 서버 로그(호스팅): GitHub Pages 등 호스팅 환경에서 일반적인 접속 로그가 남을 수 있음

2. 이용 목적

  • 날씨·달력·IP 등 요청하신 기능 제공
  • 문의 접수 및 회신
  • 서비스 오류 확인과 품질 개선
  • 법령상 의무 이행

3. 보관 및 파기

문의 내용은 회신 목적에 필요한 기간 동안 보관하며, 목적 달성 후 지체 없이 파기합니다. 브라우저 localStorage에 저장된 설정값은 이용자가 직접 삭제하거나 브라우저 데이터를 지우면 제거됩니다. 위치 정보는 서버에 장기 저장하지 않고, 조회 요청 처리에 사용됩니다.

4. 제3자 서비스

기능 제공을 위해 아래와 같은 외부 서비스를 사용할 수 있습니다.

  • Open-Meteo(날씨 데이터)
  • ipify / ipwho.is 등 IP·지역 정보 API
  • Formspree(문의 양식 전송)
  • Google Fonts 등 폰트·CDN
  • GitHub Pages(호스팅)

각 서비스는 해당 업체의 정책에 따라 데이터를 처리할 수 있습니다.

5. 쿠키 및 맞춤 광고(애드센스)

향후 Google AdSense 등 광고 서비스를 사용할 경우, Google을 포함한 제3자 공급업체가 쿠키를 사용해 사용자 방문 정보를 기반으로 광고를 게재할 수 있습니다. 이용자는 Google 광고 설정에서 맞춤 광고를 거부할 수 있으며, www.aboutads.info에서 제3자 공급업체의 맞춤 광고 사용을 거부할 수 있습니다.

쿠키를 사용하지 않도록 설정하면 맞춤 광고가 게재되지 않을 수 있습니다.

6. 이용자의 권리

이용자는 문의 페이지를 통해 본인 관련 문의 내용의 열람·수정·삭제 요청을 할 수 있습니다. 브라우저에 저장된 설정은 이용자 기기에서 직접 관리할 수 있습니다.

7. 아동의 개인정보

사이트는 아동을 대상으로 한 서비스를 운영하지 않으며, 만 14세 미만 아동의 개인정보를 고의로 수집하지 않습니다.

8. 방침 변경

본 방침이 변경되면 페이지 상단의 업데이트 날짜를 수정하고 사이트에 게시합니다.

9. 문의

개인정보 관련 문의는 문의 페이지로 남겨 주세요.
